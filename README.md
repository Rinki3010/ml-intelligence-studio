# Forma — AI Intelligence Studio

A UI-first AI/ML workflow studio prototype, now connected to a local FastAPI backend for a real end-to-end classification pipeline.

## Prerequisites
- Node.js 20+ and npm
- Python 3.10+ (Python 3.11 recommended)

## Start the backend (PowerShell)
Open a terminal at the project root:

```powershell
cd backend
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

API docs: http://127.0.0.1:8000/docs
Health check: http://127.0.0.1:8000/api/v1/health

## Start the frontend
In a second terminal, from the project root:

```powershell
cd frontend
npm install
npm run dev
```

Open the Vite URL, usually http://localhost:5173. The Vite development server proxies `/api` requests to the backend at port 8000. Start the backend first.

## Run the full pipeline from the UI
Open **Pipeline Studio** and select **Run pipeline**. It executes real Python/scikit-learn code:

1. Generate a reproducible 320-row synthetic binary classification dataset.
2. Validate schema, target classes, and missing values.
3. Create a stratified 75/25 train/test split.
4. Train a baseline Random Forest classifier.
5. Run an 8-candidate, 3-fold GridSearchCV on training data only.
6. Evaluate baseline and tuned models against the same held-out test set.
7. Run an F1 quality gate with a default threshold of 0.70.
8. Save dataset, model files, tuning trials, feature importance, evaluation report, and logs.

Run history and metadata are stored in SQLite (`backend/studio.sqlite3`). Artifacts are stored in `artifacts/<run_id>/`. The UI shows measured metrics and artifact download links for a completed run.

A tuning run is not guaranteed to outperform the baseline. Both are reported honestly using the same held-out test set; hyperparameter selection does not use test labels.

## API
- `GET /api/v1/health`
- `GET /api/v1/components`
- `POST /api/v1/pipelines/classification/run`
- `GET /api/v1/runs`
- `GET /api/v1/runs/{run_id}`
- `GET /api/v1/runs/{run_id}/analytics` (CSV-backed permutation importance, held-out prediction samples, feature-engineering details, target distribution, and data-quality summary)
- `GET /api/v1/artifacts/{run_id}/{filename}`

Example request:

```json
{
  "config": {
    "samples": 320,
    "random_seed": 42,
    "test_size": 0.25,
    "quality_threshold": 0.7,
    "run_tuning": true
  }
}
```

## Implemented vs planned
- **Implemented:** real synthetic dataset generation, validation, stratified split, baseline training, GridSearchCV tuning, held-out evaluation, F1 quality gate, SQLite run history, local artifact downloads, component catalogue API, UI execution and result summary.
- **Implemented for CSV-backed runs:** model-agnostic permutation importance computed on the held-out test split; prediction samples with actual/predicted labels and class probabilities when available; numeric/categorical transformation report; target distribution; feature correlation summary; and a Feature Engineering UI view. The Explainability Studio loads these measured analytics for the latest run in the current browser session.
- **Still planned:** SHAP-specific local attribution plots, editable feature-transformation controls, arbitrary editable DAG execution, LLM provider integration, deployment, multi-user security, distributed workers, and production-grade job cancellation. The LLM interpretation card is not connected to an LLM and does not claim to be generated by one.

## Security note
This is a local development prototype. Do not expose the execution API to untrusted users. Before production, add authentication/authorization, resource limits, isolated component execution, stronger artifact access controls, and job queue/cancellation semantics.

## Bring your own CSV (local backend)

1. Start the backend from `backend` with `python -m uvicorn app.main:app --reload --port 8000`.
2. Start the frontend from `frontend` with `npm run dev`.
3. In Forma, select **+ New ML project**, upload a `.csv`, select a target column and choose classification or regression.
4. Select **Generate & run pipeline**. The API profiles the uploaded file, preprocesses numeric/categorical features, trains a baseline Random Forest, optionally tunes on training data only, evaluates on a held-out test set, and saves artifacts.

CSV endpoints:
- `POST /api/v1/datasets/upload` (multipart form field `file`)
- `POST /api/v1/datasets/{dataset_id}/run` (JSON: `target_column`, `task`, `test_size`, `random_seed`, `run_tuning`, `quality_threshold`)

The local prototype accepts CSV files up to 50 MB. Use only data you are authorized to process. Uploaded datasets are stored under `data/uploads`; run artifacts are stored under `artifacts/<run_id>`.
